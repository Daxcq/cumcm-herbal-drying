# 圆柱形药材烘干数学建模项目

本仓库保存全国大学生数学建模竞赛 A 题“药材烘干问题”的数值程序、原始附件、结果生成脚本和复核脚本。四问均采用轴对称一维径向有限体积离散；问题二、三使用附录3场相关物性并迭代耦合温度场与干基含水率场，问题四进一步引入附件2给出的收缩半径及附录4物性。

## 目录

```text
data/raw/                 附件1、附件2
src/q1_preheat/           问题一：附录2常物性预热模型
src/q2_full/              问题二：附录3变物性耦合模型
src/q3_drying/            问题三：阈值判定与边界延拓
src/q4_shrinkage/         问题四：附录4物性与收缩半径
scripts/build_deliverables.py  生成 result1.xlsx 至 result4.xlsx
scripts/run_q3_audits.py       问题二、三守恒及敏感性复核
outputs/                  程序输出目录
```

## 环境与运行

建议使用 Python 3.10 或更高版本。

```bash
python -m pip install -r requirements.txt
python scripts/build_deliverables.py
python scripts/run_q3_audits.py
```

第一条生成题目要求的四个 Excel 结果文件；第二条生成 `outputs/q3/q3_audit.json`。程序中的输入路径均相对于仓库根目录解析，不要求从某个固定工作目录启动。

正式结果采用5 s时间步长；10 s结果仅用于时间步长收敛对照。

## 统一建模口径

- 药材初温为 28 ℃，温度参与 Arrhenius 公式前统一换算为 K。
- 问题一热扩散率为
  `alpha = 0.36 / (820 * 2600) = 1.6886e-7 m^2/s`。
- 烘房温度在 0—7200 s 使用拟合曲线，7200 s 后按恒温设定值处理。
- 附件1仅提供0—14400 s的烘房边界数据；14400 s 后将烘房水分浓度延拓为末时刻平台值，并通过正负3倍平台噪声标准差检验该假设的敏感性。
- 药材内部变量称为“干基含水率”；“水分浓度”只用于烘房环境边界。
- 问题三、四的达标时刻由相邻时间步对最大干基含水率作线性插值得到，Excel 显示值按四位小数输出。

## 主要结果

- 问题三达标时间：57.5341 h（207122.90 s）。
- 问题四达标时间：51.1082 h（183989.55 s）。
- 问题二最大相对质量守恒残差：0.2471%。
- 问题三最大相对质量守恒残差：0.1094%。
- 边界延拓正负3σ扰动下，问题三烘干时间最大相对变化为1.61%。

问题三与问题四同时改变了物性参数和几何尺寸，因此两者烘干时间之差应解释为“附录4物性与尺寸收缩的综合作用”，不能全部归因于收缩。

## 输出说明

- `result1.xlsx`、`result2.xlsx`：温度和干基含水率两个工作表，距离间隔0.1 cm。
- `result3.xlsx`：每60 s输出一次干基含水率剖面。
- `result4.xlsx`：每60 s输出一次干基含水率剖面，并给出实际半径和表面值；固定物理坐标落到收缩后药材外部时保留为空白。

原始附件与最终提交文件须以竞赛组委会要求为准。本仓库仅用于本队建模过程的复现与核验。


## 已上传结果的还原

由于 GitHub 单文件传输限制，`outputs/q2/result2.xlsx` 以五个无损分片保存。克隆仓库后执行：

```bash
python scripts/assemble_result2.py
```

脚本会自动生成原始 Excel 文件并进行 SHA-256 校验。其余三个结果文件可直接位于 `outputs/` 对应目录中。
