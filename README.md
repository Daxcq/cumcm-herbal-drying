# 药材烘干数学建模项目

## 项目简介

本项目是针对药材烘干过程的数学建模与数值模拟研究，使用偏微分方程（PDE）描述药材内部的温度场和水分场耦合演化过程。

## 问题描述

研究药材烘干过程中的热量传递和水分扩散现象，建立温度-水分耦合的数学模型，并通过数值方法求解。

## 主要功能

### 1. 问题1：预热平衡阶段求解器 (`solver_q1.py`)

**模型方程**：
- 温度场：`dT/dt = α∇²T`，其中 `α = k/(ρ·cp)`
- 水分场：`dC/dt = ∇·(D(C)∇C)`，其中 `D(C) = 7×10⁻⁹·exp(-0.89/C)`

**数值方法**：
- 空间离散：有限体积法（轴对称）
- 时间积分：Crank-Nicolson格式
- 非线性求解：Picard迭代

**运行方式**：
```bash
python solver_q1.py [网格数] [时间步长]
# 示例：python solver_q1.py 21 0.5
```

**输出**：
- `outputs/q1/result1_v2.xlsx` - 温度和水分分布表格
- `outputs/q1/q1_v2.npz` - 完整的数值结果

### 2. 数据统计分析 (`data_analysis.py`)

对附件1和附件2进行全面的统计分析：

- **描述性统计**：均值、方差、偏度、峰度、变异系数
- **正态性检验**：Shapiro-Wilk检验
- **相关性分析**：Pearson相关系数矩阵与热力图
- **多模型拟合对比**：指数、多项式、对数、幂函数、Logistic等
- **残差分析**：系统性偏差检验、Durbin-Watson检验

**运行方式**：
```bash
python data_analysis.py
```

**关键发现**：
- 温度与水分含量呈极强正相关（**r=0.983**）
- 验证了温度-水分耦合模型的物理合理性

### 3. 水分-温度关系拟合 (`analyze_moisture_vs_temperature.py`)

分析环境温度与水分浓度的函数关系：

**拟合方程**：
```
w(T) = 0.01332 + 0.0009421 × e^(0.0731×T)
```

**拟合精度**：
- R² = 0.9964
- RMSE = 0.000488 kg/kg
- MAPE = 0.96%

**运行方式**：
```bash
python analyze_moisture_vs_temperature.py
```
