## 一、附件1：烘房环境温度和水分含量

### 1.1 数据基本信息
- **样本数**: 241个观测点
- **时间跨度**: 0 - 14400秒（4小时）
- **变量**: 温度(°C)、水分含量(kg/kg)

### 1.2 描述性统计发现

#### 温度(°C)
- **均值**: 47.25°C
- **标准差**: 5.11°C
- **范围**: 28.00°C - 50.25°C
- **偏度**: -2.158（显著左偏，说明大部分数据集中在高温区）
- **峰度**: 3.758（尖峰分布，存在极端值）
- **变异系数**: 10.8%（中等变异性）
- **正态性**: **不服从正态分布** (p < 0.001)

**解读**: 温度数据呈现左偏分布，表明烘干过程中温度快速上升后趋于稳定，大部分时间维持在高温状态。

#### 水分含量(kg/kg)
- **均值**: 0.0448 kg/kg
- **标准差**: 0.0081 kg/kg
- **范围**: 0.0196 - 0.0503 kg/kg
- **偏度**: -1.638（左偏）
- **峰度**: 1.497（尖峰分布）
- **变异系数**: 18.2%（中等变异性）
- **正态性**: **不服从正态分布** (p < 0.001)

**解读**: 水分含量也呈左偏分布，烘干过程中水分迅速降低后缓慢趋于平衡。

### 1.3 相关性分析

| 变量对 | Pearson相关系数 | 关系强度 |
|--------|----------------|----------|
| 时间 ↔ 温度 | 0.7335 | 强正相关 |
| 时间 ↔ 水分 | 0.8126 | 强正相关 |
| **温度 ↔ 水分** | **0.9833** | **极强正相关** |

**关键发现**: 
- 温度与水分含量呈现**极强正相关**（r=0.983），说明两者存在紧密的耦合关系
- 这验证了你们模型中温度场和水分场相互影响的假设

### 1.4 拟合模型对比

#### 温度拟合结果

| 模型 | R² | RMSE | MAE | MAPE(%) | 推荐度 |
|------|-----|------|-----|---------|--------|
| **三次多项式** ✓ | **0.9815** | **0.694** | **0.596** | **1.33** | ⭐⭐⭐⭐⭐ |
| 二次多项式 | 0.8751 | 1.804 | 1.488 | 3.40 | ⭐⭐⭐ |
| 对数模型 | 0.8440 | 2.016 | 1.400 | 3.32 | ⭐⭐⭐ |
| 指数模型 | 0.5380 | 3.469 | 2.702 | 6.34 | ⭐⭐ |
| 双指数模型 | 0.2338 | 4.468 | 2.731 | 6.65 | ⭐ |

**最佳模型**: 三次多项式
```
T(t) = 29.946 + 0.00725t - 8.197×10⁻⁷t² + 3.24×10⁻¹¹t³
```

**残差分析**:
- 残差均值: 2.78×10⁻¹¹ ≈ 0 ✓（无系统性偏差）
- Durbin-Watson: 0.081（存在正自相关，说明时间序列相邻点高度相关）

#### 水分含量拟合结果

**最佳模型**: 三次多项式
```
C(t) = 0.0192 + 9.39×10⁻⁶t - 9.04×10⁻¹⁰t² + 2.66×10⁻¹⁴t³
```

**残差分析**:
- 残差均值: 6.37×10⁻¹³ ≈ 0 ✓
- MAPE仅0.79%，拟合精度极高
