# 问题二、问题三数值核验

## 核验口径

问题二、三采用相同的轴对称有限体积骨架和附录3场相关物性。烘房温度在7200 s后固定为恒温设定值；附件1的水分浓度数据使用至14400 s，此后延拓为末时刻平台值。问题三正式达标时刻采用5 s时间步长并对阈值跨越作线性插值。

## 正式结果

| 项目 | 数值 |
|---|---:|
| 问题三达标时刻 | 207122.90 s |
| 问题三达标时间 | 57.5341 h |
| 问题二最大相对质量守恒残差 | 0.2471% |
| 问题三最大相对质量守恒残差 | 0.1094% |

表格中显示为0.1500的阈值行，是相邻时间步插值得到的阈值时刻；单元格仅保留四位小数，不表示未经插值直接命中阈值。

## 边界延拓敏感性

利用7200—14400 s平台段估计边界噪声，温度标准差为0.1648 ℃，烘房水分浓度标准差为0.0002924。分别施加正负3倍标准差的有利和不利扰动后，10 s收敛对照计算所得烘干时间最大相对变化为1.61%，说明4 h后恒温、恒湿延拓不会改变主要结论。

## 复现

```bash
python scripts/build_deliverables.py
python scripts/run_q3_audits.py
python -m unittest discover -s tests
```

完整数值写入 `outputs/q3/q3_audit.json`。守恒核查基于0.1 cm输出剖面独立积分，因此与求解器内部细网格并非同一套计算，残差同时包含时间离散、空间抽样和数值积分误差。
