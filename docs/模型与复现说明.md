## 覆盖方式

将压缩包内容解压到仓库根目录，允许覆盖 `README.md` 和 `src/q1_preheat/solver_q1.py`。不要删除仓库中原有的 `data/raw/附件1.xlsx` 与 `data/raw/附件2.xlsx`。

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/build_deliverables.py
python scripts/run_q3_audits.py
```

预期正式结果：问题三 `207122.90 s`，问题四 `183989.55 s`。

建议新建分支后提交，不要直接覆盖主分支：

```bash
git switch -c final-reproducibility
git add README.md requirements.txt src scripts tests docs/model/问题2问题3数值核验.md
git commit -m "补齐四问求解器与可复现性检查"
git push -u origin final-reproducibility
```
