# 绝对路径转相对路径 - 修改总结

## 修改日期
2026年9月11日

## 问题描述

项目代码中存在硬编码的绝对路径（`D:/mcm-kitpip-cache/...`），导致：
- ❌ 代码无法在其他机器上运行
- ❌ 项目路径变更后需要手动修改所有路径
- ❌ 不符合可移植性要求
- ❌ 团队协作困难

## 相对路径规则

### Python 模块路径约定

从源代码目录访问数据文件，使用 `../../` 回到项目根目录：

```
项目结构:
cumcm-herbal-drying/
├── data/raw/附件1.xlsx          # 目标文件
├── src/
│   ├── q1_preheat/
│   │   └── solver_q1.py        # 当前位置
│   └── analysis/
│       └── moisture_temperature.py  # 当前位置
```

**路径计算**:
- 从 `src/q1_preheat/` → `data/raw/`: `../../data/raw/`
- 从 `src/analysis/` → `data/raw/`: `../../data/raw/`
- 从 `src/analysis/` → `outputs/`: `../../outputs/`

### JavaScript 模块路径约定

使用 Node.js 内置的 `path` 模块和 `import.meta.url`：

```javascript
import { fileURLToPath } from "node:url";
import { dirname, join } from "node:path";

const __filename = fileURLToPath(import.meta.url);
const __dirname = dirname(__filename);
const projectRoot = join(__dirname, "..");
```

## 使用说明

### 运行代码的正确方式

**方式1：从模块所在目录运行**
```bash
cd src/q1_preheat
python solver_q1.py
```

**方式2：作为模块导入（推荐）**
```bash
cd 项目根目录
python -m src.q1_preheat.solver_q1
```

**方式3：使用脚本（未来推荐）**
```bash
cd 项目根目录
python scripts/run_solver.py
```

## 注意事项

⚠️ **工作目录要求**
- Python脚本需要从对应的源码目录运行
- 或者使用 `-m` 参数作为模块运行

⚠️ **路径分隔符**
- 使用 `/` 而不是 `\\`（即使在Windows上）
- Python 和 Node.js 会自动处理平台差异

⚠️ **数据文件位置**
- 确保 `data/raw/` 下有必要的数据文件
- 首次运行会自动创建输出目录
