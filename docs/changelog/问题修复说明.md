### 问题2：`solver_q1.py` 边界条件需要使用拟合公式

**问题描述**：
数值模拟中边界水分浓度 `C_amb` 原本使用线性插值：
```python
C_amb = np.interp(times, t_env, C_env)
```

但应该使用温度-水分拟合公式计算，以保持一致性。

**修复方案**：
1. 新增 `C_fitted(T)` 函数，使用预热阶段拟合参数：
```python
def C_fitted(T):
    """
    使用预热阶段拟合公式计算水分浓度
    w = 0.0118 + 0.001318 × e^(0.067×T)
    适用范围: T ∈ [28, 49.94] °C
    """
    a = 0.0118
    b = 0.001318
    c = 0.067
    return a + b * np.exp(c * T)
```

2. 修改 `run()` 函数第151行：
```python
# 旧代码
C_amb = np.interp(times, t_env, C_env)

# 新代码
C_amb = C_fitted(T_amb)
```

**优势**：
- ✅ 边界条件更平滑（拟合曲线连续可导）
- ✅ 与拟合分析保持一致
- ✅ 物理意义更明确（水分随温度的关系）
- ✅ 避免插值带来的噪声

## 为什么需要这两个修复？

### 1. 关于时间 t 的问题
**你的疑问**："为什么拟合中有t（时间）？"

**回答**：
实际上有**两种拟合**：

| 文件 | 自变量 | 因变量 | 拟合关系 | 用途 |
|------|--------|--------|----------|------|
| `analyze_moisture_vs_temperature.py` | 温度 T | 水分 w | w(T) | ✅ 用于边界条件 |
| `data_analysis_with_your_model.py` | 时间 t | 水分 w | w(t) | 仅用于统计分析 |

- **w(T) 拟合**：描述环境温度与环境湿度的关系
- **w(t) 拟合**：描述水分随时间的演化（不用于数值模拟）

### 2. 为什么solver需要改？
**你的观点**："solver中有个拟合边界C_amb公式需要改成拟合公式"

**完全正确！** 因为：
1. 数值模拟需要**边界条件** C_amb(t)
2. C_amb 应该与温度相关：C_amb = w(T_amb)
3. 使用拟合公式比线性插值更合理（平滑、连续、符合物理规律）
